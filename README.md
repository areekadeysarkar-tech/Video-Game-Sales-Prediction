# 🎮 Video Game Sales Prediction

## 📌 Project Overview

The Video Game Sales Prediction project is a Machine Learning-based project that focuses on analyzing video game sales data and predicting sales outcomes using different game-related attributes.

The project uses Python and Machine Learning techniques to explore video game sales patterns, identify important factors affecting sales, and build a predictive model.

## 🎯 Project Objectives

- Analyze video game sales data.
- Understand sales trends across different platforms and genres.
- Perform data cleaning and preprocessing.
- Explore relationships between different features.
- Apply Machine Learning algorithms for sales prediction.
- Evaluate the performance of the prediction model.
